## About me

I'm **Imane Mrino**, a Networks, Cloud & Cybersecurity student at **EST Kelaa des Sraghna**, with a DUT in Computer Security & Networks from **EST Béni-Mellal**.

My interests lie in **defensive cybersecurity**, especially understanding how networks behave, making security events easier to interpret, and improving monitoring and alerting workflows.

Through internships at **CIMAT** and **Ménara Préfa**, I've gained experience with network infrastructure and developed a network-security monitoring project using Python, Flask, and SQLite.
